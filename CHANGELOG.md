# Changelog

All notable changes to Certificate Inventory will be documented in this file.

## [0.1.0] - 2026-10-07

### Added
- Initial public proof-of-concept release.
- Apache and Nginx SSL/TLS certificate discovery.
- X.509 metadata extraction with OpenSSL.
- GLPI Agent `additional-content` transport.
- Native GLPI Certificate creation/update workflow.
- Automatic Certificate-to-Computer association.
- SHA-256 fingerprint correlation.
- Manual rescan and scheduled reconciliation support.
- Ubuntu 22.04 and 24.04 client support.
